# JL You Portal — HR & Enterprise SaaS Platform

A multi-app HR/Enterprise platform built with React + Vite + Tailwind CSS, powered by Supabase (Edge Functions + PostgreSQL).

## Database Schema

All tables are defined in `supabase/migrations/001_initial_schema.sql`.

**Core tables** (shared across apps via foreign keys):
- `employees` — single source of truth for all staff data
- `app_users` — portal login accounts, linked to `employees`
- `audit_logs` — system-wide audit trail

**App tables** each have FK relationships back to `employees.id`.

## Deployment

### Prerequisites
```bash
npm install -g supabase
supabase login
```

### One-command deploy
```bash
bash deploy.sh
```

This script:
1. Bundles the canonical authenticated server into `supabase/functions/make-server-1fe2c468/`
2. Deploys the edge function with Supabase gateway JWT verification enabled
3. Verifies that an unauthenticated request is rejected

### Verify anonymous access is blocked
```bash
SUPABASE_URL=https://icmexriwtsjwpswexyrb.supabase.co \
SUPABASE_ANON_KEY=your-anon-key \
pnpm test:security:no-anon
```

Every edge-function check and the direct REST check must return HTTP 401 or 403.

### View logs
```bash
supabase functions logs make-server-1fe2c468 --project-ref icmexriwtsjwpswexyrb
```

## Database Migration

Tables were created manually via Supabase SQL Editor using `supabase/migrations/001_initial_schema.sql`.

To apply on a fresh project:
```bash
# Rename file to timestamp format first
mv supabase/migrations/001_initial_schema.sql supabase/migrations/20240821000000_initial_schema.sql
supabase db push --project-ref icmexriwtsjwpswexyrb
```

Or paste the SQL directly in the [Supabase SQL Editor](https://supabase.com/dashboard/project/icmexriwtsjwpswexyrb/sql/new).

For an existing project, run pending migrations in numeric order. In
particular, `22_deny_anon_rest_api.sql` and
`23_close_remaining_anon_surfaces.sql` must both be applied before considering
anonymous REST access closed.

## Troubleshooting

| Problem | Fix |
|---------|-----|
| `PermissionDenied` on telemetry | `sudo chown -R $(whoami) ~/.supabase` |
| `command not found: supabase` | `npm install -g supabase` |
| `Invalid Function name` | Use `make-server-1fe2c468` as the name, not `server` |
| `index.ts not found` | Run `bash deploy.sh` — it handles the rename automatically |
| Docker not running | Not needed; deploy goes directly to production via CLI |
