## 🎯 Overview

The Employee Dashboard is your personal workspace in the Portal Jeshan Labs. It provides a comprehensive view of your:
- **Performance metrics** and statistics
- **Tasks and assignments** with due dates
- **Recent activities** and actions
- **Quarterly goals** and progress tracking

### Key Benefits:
✅ **Centralized view** of all your work  
✅ **Real-time updates** from the database  
✅ **Task management** with priority levels  
✅ **Goal tracking** with visual progress bars  
✅ **Activity history** of your recent actions  

---

## 🚀 Getting Started

### Accessing the Dashboard:

1. **Login** to Portal Jeshan Labs
2. From the **Launchpad**, click on the **"Employee Dashboard"** tile
3. The dashboard will load with your personalized data

### First Time Setup:

When you first access the dashboard, default data will be created:
- **3 sample tasks** to get you started
- **3 sample activities** showing recent actions
- **3 quarterly goals** with progress tracking
- **Performance stats** including tasks completed, training hours, and more

## 📊 Dashboard Sections

### 1. **Welcome Banner**
- Personalized greeting with your name
- Overview message
- Gradient design for visual appeal

### 2. **Statistics Cards**
Four cards showing your key performance metrics:

#### Tasks Completed
- **What it shows:** Total number of tasks you've completed
- **Change indicator:** Percentage increase/decrease from last period
- **Color:** Green (success indicator)

#### Training Hours
- **What it shows:** Total hours spent in training
- **Change indicator:** Percentage increase/decrease
- **Color:** Blue (learning indicator)

#### Performance Score
- **What it shows:** Your current performance rating (out of 100%)
- **Change indicator:** Percentage improvement
- **Color:** Purple (excellence indicator)

#### Achievements
- **What it shows:** Total badges and achievements earned
- **Change indicator:** New achievements count
- **Color:** Orange (recognition indicator)

### 3. **Upcoming Tasks**
- **Location:** Left side of the screen
- **Shows:** Your next 5 tasks ordered by due date
- **Features:**
  - Task title and description

**Priority Colors:**
- 🔴 **High** - Red badge (urgent)
- 🟡 **Medium** - Default badge (important)
- ⚪ **Low** - Gray badge (can wait)

### 4. **Recent Activity**
- **Location:** Right side of the screen
- **Shows:** Your last 5 activities
- **Features:**
  - Activity description
  - Relative time ("2 hours ago", "1 day ago")
  - Blue checkmark icon

### 5. **Current Goals**
- **Location:** Bottom of the dashboard
- **Shows:** All your quarterly goals
- **Features:**
  - Goal title and category badge
  - Current vs. target progress
  - Visual progress bar
  - Deadline display

## 📝 Managing Tasks

### Viewing Tasks

Tasks are displayed with the following information:
- **Title** - Brief description of the task
- **Description** - Detailed information (if available)
- **Due Date** - When the task is due
- **Priority** - High, Medium, or Low
- **Status** - Pending, In Progress, or Completed

### Completing a Task

1. Locate the task in the "Upcoming Tasks" section
2. Click the **"Complete"** button next to the task
3. The task status will update immediately
4. A success message will appear
5. The task will move to completed status

**Note:** Completed tasks are tracked in your statistics but removed from the pending list.

### Task Status Flow

```
Pending → In Progress → Completed
```

- **Pending** - Not started yet
- **In Progress** - Currently working on it
- **Completed** - Finished

## 🎯 Tracking Goals

### Understanding Goals

Each goal has:
- **Title** - What you're trying to achieve
- **Current Progress** - Where you are now
- **Target** - What you're aiming for
- **Progress Percentage** - Visual indicator
- **Unit** - How progress is measured (modules, %, projects, etc.)
- **Category** - Type of goal (Learning, Performance, Delivery)
- **Deadline** - When the goal should be completed

### Example Goals:

#### 1. Complete 10 Training Modules
```
Category: Learning
Current: 7/10 modules
Progress: 70%
Deadline: 2026-03-31
```

#### 2. Maintain 90% Performance Score
```
Category: Performance
Current: 92/90 %
Progress: 100% (exceeded!)
Deadline: 2026-03-31
```

#### 3. Complete Client Projects
```
Category: Delivery
Current: 4/5 projects
Progress: 80%
Deadline: 2026-03-31
```

### Goal Categories

- **📚 Learning** - Training, courses, certifications
- **📈 Performance** - KPIs, ratings, scores
- **🚀 Delivery** - Projects, tasks, outputs
- **🤝 Teamwork** - Collaboration, mentoring
- **💡 Innovation** - Ideas, improvements, initiatives

## 📝 Activity Feed

### What Gets Tracked?

Activities are automatically logged when you:
- ✅ Complete a task
- 📚 Finish a training module
- 📊 Update a project status
- 📄 Submit a report
- 🏖️ Request leave
- ⚙️ Change settings
- 💬 Post in Communications Hub

### Activity Format

Each activity shows:
```
Action: "Completed training module: 'Leadership Skills'"
Time: "2 hours ago"
```

### Activity Retention

- Last **20 activities** are stored
- Older activities are automatically archived
- Activities are sorted by most recent first

## 🔧 Troubleshooting

### Dashboard Not Loading

**Problem:** Blank screen or loading spinner doesn't stop

**Solution:**
1. Click the **"Refresh"** button in the top-right corner
2. Check your internet connection
3. Log out and log back in
4. Clear browser cache

### Data Not Updating

**Problem:** Changes not saving

**Solution:**
1. Ensure you're connected to the internet
2. Check for error messages (they appear as toast notifications)
3. Try refreshing the page
4. Contact IT Support if issue persists

### Tasks Not Appearing

**Problem:** Created tasks don't show up

**Solution:**
1. Click the **Refresh** button
2. Check if tasks are filtered by status
3. Verify task was created successfully (check for success message)

### Performance Stats Incorrect

**Problem:** Stats showing wrong numbers

**Solution:**
1. Refresh the dashboard
2. Check if recent activities have updated stats
3. Stats may take a few minutes to reflect changes
4. Contact your manager if numbers seem significantly off

## 📞 Getting Help

### Support Resources:

1. **User Documentation** - Access the full documentation portal
2. **IT Services** - Submit a support ticket
3. **Internal Communications Hub** - Ask questions in the #help channel
4. **Manager** - Reach out to your direct supervisor

### Common Questions:

**Q: How often is data updated?**  
A: Data updates in real-time. Any changes are saved immediately to the database.

**Q: Can I create my own tasks?**  
A: Currently, task creation is managed through other applications. The dashboard displays tasks assigned to you.

**Q: How are goals calculated?**  
A: Goals are set by you or your manager. Progress is calculated as (current/target) × 100%.

**Q: Can I see historical data?**  
A: Currently, the dashboard shows current data. Historical reporting will be added in future updates.

**Q: Is my data private?**  
A: Yes, your dashboard data is private and only visible to you and your manager.
